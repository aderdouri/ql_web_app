Chapter Overview

This chapter demonstrates how to set up term structures so that they track (or don't track) the global evaluation date in QuantLib. Learn about reference dates, curve construction methods, and the observer pattern for automatic recalculation.

What You'll Learn:
  • Setting up term structures with reference dates
  • PiecewiseFlatForward vs ForwardCurve construction
  • Impact of evaluation date changes
  • Observer pattern for automatic updates
Key Concepts:
  • Reference Date
  • Evaluation Date
  • SwapRateHelper
  • Observer Pattern

Notebook Inputs

Input 1: Evaluation Date Setup
In [1]:
import QuantLib as ql

In [2]:
ql.Settings.instance().evaluationDate = ql.Date(3, ql.October, 2014)

Sets the global evaluation date for all QuantLib calculations.

Input 2: Swap Rate Helpers
In [3]:
helpers = [
  ql.SwapRateHelper(
    ql.QuoteHandle(ql.SimpleQuote(rate/100.0)),
    ql.Period(*tenor), ql.TARGET(),
    ql.Annual, ql.Unadjusted,
    ql.Thirty360(ql.Thirty360.BondBasis),
    ql.Euribor6M())
  for tenor, rate in [
    ((2,ql.Years), 0.201),
    ((3,ql.Years), 0.258),
    ((5,ql.Years), 0.464),
    ((10,ql.Years), 1.151),
    ((15,ql.Years), 1.588)]
]

Creates swap rate helpers for curve construction with market data.

Input 3: PiecewiseFlatForward Curve
In [4]:
curve1 = ql.PiecewiseFlatForward(
  0, ql.TARGET(), helpers, ql.Actual360())

Creates a curve with reference date relative to evaluation date (0 days offset).

Input 4: ForwardCurve Construction
In [5-7]:
dates, rates = zip(*curve1.nodes())
curve2 = ql.ForwardCurve(dates, rates, ql.Actual360())

Creates a curve with explicit reference date (first date in the list).

Key Takeaways

Reference Date Concepts:
  • PiecewiseFlatForward: Reference date relative to evaluation date
  • ForwardCurve: Reference date explicitly specified
  • Both methods: Can produce equivalent results
Practical Applications:
  • Risk Management: Understanding date dependencies
  • Model Validation: Comparing different curve constructions
  • System Design: Observer pattern for automatic updates
