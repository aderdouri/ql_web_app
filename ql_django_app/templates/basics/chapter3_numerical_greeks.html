Key Concepts

Delta (Δ)

Measures how much the option price changes when the underlying asset price changes by $1.

Gamma (Γ)

Measures how fast Delta itself changes, indicating the curvature of the option price.

Rho (ρ)

Measures how much the option price changes when the interest rate changes by 1%.

Vega (ν)

Measures how much the option price changes when volatility changes by 1%.

Mathematical Foundation

Greeks are calculated using numerical differentiation methods. For a given option price function V(S, r, σ), we compute the partial derivatives using finite differences:

Delta (First Order)

Δ = ∂V/∂S ≈ (V(S+h) - V(S-h)) / (2h)

Gamma (Second Order)

Γ = ∂²V/∂S² ≈ (V(S+h) - 2V(S) + V(S-h)) / h²

Rho (Interest Rate)

ρ = ∂V/∂r ≈ (V(r+h) - V(r-h)) / (2h)

Vega (Volatility)

ν = ∂V/∂σ ≈ (V(σ+h) - V(σ-h)) / (2h)
