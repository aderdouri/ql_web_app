Key Concepts

Delta (Δ)

Measures price sensitivity to underlying asset movements

Gamma (Γ)

Measures the rate of change of Delta

Vega (ν)

Measures sensitivity to volatility changes

Rho (ρ)

Measures sensitivity to interest rate changes

Theta (Θ)

Measures time decay of option value

Code Examples

Here are some key code snippets for calculating numerical Greeks in QuantLib:

Delta Calculation
# Forward difference for Delta
h = 0.01
price_up = option.NPV(spot + h)
price_down = option.NPV(spot - h)
delta = (price_up - price_down) / (2 * h)
Gamma Calculation
# Second derivative for Gamma
price_center = option.NPV(spot)
gamma = (price_up - 2*price_center + price_down) / (h * h)
