Random Number Generators

Linear Congruential Generator

Simple and fast random number generator using linear recurrence relations.

  • Fast generation
  • Deterministic sequences
  • Limited period length
Mersenne Twister

High-quality random number generator with very long period and good statistical properties.

  • Very long period
  • Excellent statistical properties
  • Widely used in finance
Sobol Sequences

Low-discrepancy sequences that provide better coverage of the unit hypercube.

  • Quasi-random sequences
  • Faster convergence
  • Deterministic
Halton Sequences

Another type of low-discrepancy sequence useful for Monte Carlo integration.

  • Low discrepancy
  • Easy to implement
  • Good for high dimensions

Monte Carlo Methods

Crude Monte Carlo

Basic Monte Carlo simulation using random sampling.

  • • Simple implementation
  • • Slow convergence
  • • High variance
Antithetic Variates

Variance reduction technique using negatively correlated samples.

  • • Reduces variance
  • • Easy to implement
  • • Works well for symmetric payoffs
Control Variates

Variance reduction using correlated random variables with known expectations.

  • • Significant variance reduction
  • • Requires known expectations
  • • More complex implementation
