Chapter Overview

This chapter addresses a critical issue in calculating the **Modified Duration** of floating-rate bonds. Unlike fixed-rate bonds, floating-rate bonds have coupons that reset periodically based on a reference rate (e.g., Euribor). The challenge lies in ensuring that the yield curve used for duration calculation properly affects both the discounting of cash flows and the forecasting of future coupon rates.

You will learn about the common pitfall of using generic duration functions that treat floating-rate bonds as fixed-rate bonds, and discover the correct approach using QuantLib's curve linking capabilities. We'll demonstrate how proper curve linking ensures that both discounting and forecasting react appropriately to yield changes, resulting in accurate duration calculations.

What You'll Learn:
  • Why generic duration functions fail for floating-rate bonds.
  • How to properly link forecast curves to yield curves in QuantLib.
  • The finite difference method for duration calculation.
  • Comparing correct vs. incorrect duration calculations.
  • Handling credit spreads in duration calculations.

Key Concepts

The Problem

Generic duration functions treat floating-rate bonds as fixed-rate bonds, only considering yield changes for discounting but not for forecasting future coupon rates.

Curve Linking

The solution involves linking the forecast curve to the yield curve being modified, ensuring that both discounting and forecasting react to yield changes.

Finite Difference Method

Duration is calculated using the formula: -(1/P) × (P(+) - P(-)) / (2×dy), where P(+) and P(-) are prices with slightly different yields.

Credit Spreads

The methodology works even when credit spreads are applied to the discounting curve, as long as the forecast curve is properly linked.

Technical Implementation Steps

  1. Setup: Create a floating-rate bond with Euribor6M index and add past fixings for known coupon rates.
  2. Incorrect Method: Use generic BondFunctions.duration() which treats the bond as fixed-rate, resulting in duration close to time to maturity.
  3. Correct Method: Link the forecast curve to the yield curve being modified using forecast_curve.linkTo(yield_curve).
  4. Finite Difference: Calculate P(+) and P(-) by slightly adjusting the yield and recalculating bond prices.
  5. Duration Formula: Apply the formula -(1/P) × (P(+) - P(-)) / (2×dy) to get the correct modified duration.
  6. Verification: Compare results to show that correct duration approximates time to next coupon reset, not time to maturity.
