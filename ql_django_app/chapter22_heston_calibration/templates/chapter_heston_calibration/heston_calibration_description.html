Chapter 23: Heston Model Parameter Calibration

Advanced Parameter Calibration Techniques

This chapter demonstrates how to calibrate Heston model parameters using both QuantLib Python and SciPy optimization methods. We'll explore different solvers and their performance characteristics.

Local Optimization Methods
  • QuantLib Levenberg-Marquardt: Built-in QuantLib solver
  • SciPy Levenberg-Marquardt: Enhanced SciPy implementation
  • SciPy Least Squares: Robust least squares optimization

These methods find local minima and are sensitive to initial conditions.

Global Optimization Methods
  • Differential Evolution: Global search algorithm
  • Basin Hopping: Annealing-like method

These methods search for global minima and are less sensitive to initial conditions.
