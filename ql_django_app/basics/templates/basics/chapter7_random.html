Chapter Overview

This chapter explores the fundamental concepts of random number generation and dimensionality in quantitative finance. We'll examine different types of random number generators and their impact on Monte Carlo simulations.

Key Concepts

Random Number Generators
  • Mersenne Twister: High-quality pseudo-random number generator
  • Sobol Sequences: Low-discrepancy quasi-random sequences
  • Inverse Cumulative Normal: Transforms uniform to normal distribution
Monte Carlo Applications
  • Option Pricing: European options with different RNGs
  • Correlated Assets: Multi-dimensional simulations
  • Convergence Analysis: Comparing RNG performance

Mathematical Background

Unit Square Coverage

The goal is to generate points within a (0,1) × (0,1) unit square. For a 2-dimensional problem, pseudo-random numbers can be generated individually and then paired.

Sobol Sequences

Sobol sequences are low-discrepancy sequences that provide more uniform coverage than pseudo-random numbers. Even coverage is only obtained for a number of samples of the form n = 2^i - 1 for some i.

Dimensionality in Monte Carlo

The QuantLib Monte Carlo framework checks the dimensionality of random number generators. For a simulation with 3 factors over 4 time steps, we need 3 × 4 = 12 random numbers.

Code Examples

QuantLib Setup
import QuantLib as ql
import matplotlib.pyplot as plt

# Setup QuantLib
today = ql.Date(27, ql.January, 2018)
ql.Settings.instance().evaluationDate = today

# Helper function for unit square plots
def set_unit_square(ax):
    ax.axis('scaled')
    ax.set_xlim([0,1])
    ax.set_ylim([0,1])
Random Number Generation
# Mersenne Twister (pseudo-random)
rng = ql.MersenneTwisterUniformRng(42)
xs = []
ys = []
for i in range(2847):
    xs.append(rng.next().value())
    ys.append(rng.next().value())

# Sobol sequence (quasi-random)
rng = ql.SobolRsg(2)
xs = []
ys = []
for i in range(2047):
    x, y = rng.nextSequence().value()
    xs.append(x)
    ys.append(y)
