Chapter Overview

Treasury futures contracts are financial derivatives that give the buyer the right to buy the underlying Treasury security by the time the contract expires. The underlying is usually delivered from a basket of securities, making the valuation more complex than simple futures contracts.

In this chapter, we will learn how to value treasury futures contracts using QuantLib. We start by doing a naive calculation by constructing a fictional security to see what is wrong about this approach. As a next step, we will perform the cheapest to deliver calculation and subsequently use that deliverable to value the same contract.

What You'll Learn:
  • Treasury futures contract modeling with QuantLib
  • Cheapest to Deliver (CTD) calculations
  • Conversion factor and basis calculations
  • Futures pricing using BondForward class

Key Concepts

Futures Contract

Agreement to buy/sell an asset at a predetermined price on a future date

Deliverable Basket

Multiple securities that can be delivered to fulfill the contract

Cheapest to Deliver (CTD)

The security that minimizes the seller's cost

Conversion Factor

Price adjustment factor for different deliverable securities

Methodology

Naive Approach

Start with a fictional 6% coupon bond as the deliverable. This approach shows the problems with using an arbitrary deliverable.

  • High Z-Spread (71 basis points)
  • Unrealistic pricing
  • Doesn't reflect market reality
Cheapest to Deliver

Calculate which security from the deliverable basket minimizes the seller's cost.

  • Basis = Cash Price - Adjusted Futures Price
  • Adjusted Futures Price = Futures Price × Conversion Factor
  • CTD has the lowest basis
