Quick Guide to Option Terms

Delta: Price sensitivity - how much option price changes when futures price moves $1

Gamma: Delta sensitivity - how much Delta changes when futures price moves $1

Theta: Time decay - how much option loses value each day

Vega: Volatility risk - how much option price changes when volatility changes 1%

Rho: Interest rate risk - how much option price changes when interest rate changes 1%

ITM/OTM/ATM: In-the-Money / Out-of-the-Money / At-the-Money
