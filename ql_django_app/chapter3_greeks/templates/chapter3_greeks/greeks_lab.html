{% if results.greeks.Delta >= 0.99 %}
Deep In-The-Money Option

The Delta is very close to 1.0. This is because the option is so deeply "in-the-money" (Spot >> Strike) that it's almost certain to be exercised. It now behaves almost exactly like the underlying stock.

Consequently, the Gamma and Vega are close to zero. The option's value is now dominated by its intrinsic value (Spot - Strike), so changes in Delta (Gamma) or Volatility (Vega) have very little impact.

{% elif results.greeks.Delta <= 0.01 %}
Far Out-of-The-Money Option

The Delta, Gamma, and Vega are all close to zero. This is because the option is so far "out-of-the-money" (Strike >> Spot) that the probability of it finishing with any value is extremely low.

{% else %}
At-The-Money / Near-The-Money Option

The option is near the strike price. This is where Gamma and Vega are typically at their highest, as the option's value is most sensitive to changes in the spot price and volatility.
