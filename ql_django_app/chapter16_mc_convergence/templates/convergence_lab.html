What is Monte Carlo Convergence?

Monte Carlo convergence measures the accuracy of numerical simulations. The higher the number of simulated paths, the closer the results get to theory. This page allows you to explore how Hull-White model parameters affect this convergence.

Hull-White Model Parameters
Key parameters: These values control the behavior of the Hull-White model
{{ form.a|as_crispy_field }}
a (Mean Reversion): Speed at which interest rates return to their mean. The higher a is, the faster the mean reversion.
{{ form.sigma|as_crispy_field }}
σ (Volatility): Measures the amplitude of interest rate fluctuations. The higher σ is, the more volatile the rates are.
Simulation Parameters
Performance Tips:
• 100 paths = Fast (~1-2 seconds)
• 500 paths = Medium (~5-10 seconds)
• 1000+ paths = Slow but more accurate (~30+ seconds)
{{ form.num_paths|as_crispy_field }}
Number of paths: The more paths, the more accurate the simulation but the longer it takes.
{{ form.time_steps|as_crispy_field }}
Time steps: Number of discretization points in time. The more steps, the more accurate the simulation.
{{ form.simulation_length|as_crispy_field }}
Duration (years): Time horizon of the simulation. The longer the duration, the more error can accumulate.
Additional Parameters

Technical Glossary

Convergence Error

Difference between theoretical value and Monte Carlo simulated value

Discount Factor

Present value of one euro received in the future, calculated with interest rates

Monte Carlo Simulation

Numerical method using random numbers to solve complex problems

Mean Reversion

Tendency of interest rates to return to their long-term average level

Volatility

Measure of the amplitude of interest rate fluctuations over time

Standard Deviation

Statistical measure of the dispersion of values around the mean
