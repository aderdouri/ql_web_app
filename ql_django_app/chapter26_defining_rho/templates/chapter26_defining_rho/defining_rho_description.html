Key Concepts

Process Types

QuantLib provides different process classes for various Black-Scholes scenarios with different dividend constraints.

  • BlackScholesProcess: q(t) = 0 (no dividends)
  • BlackProcess: q(t) = r(t) (cost of carry = 0)
  • Generalized: q(t) = continuous dividend yield
Rho Calculation

Rho measures the sensitivity of option price to changes in the risk-free interest rate.

  • Analytical: ∂V/∂r
  • Numerical: (V(r+Δr) - V(r-Δr))/(2Δr)
