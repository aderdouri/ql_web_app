Understanding the Rho Glitch
Why the Glitch Occurs

The BlackProcess constrains dividend yield to equal risk-free rate (q = r). This constraint affects rho calculation:

  • Analytic rho: Doesn't account for q = r constraint
  • Numerical rho: Correctly captures the constraint effect
The Solution

Manual correction is needed for BlackProcess:

  • Standard rho: {{ results.option_2_rho_analytic|floatformat:6 }}
  • Dividend rho: {{ results.dividend_rho|floatformat:6 }}
  • Corrected rho: {{ results.option_2_rho_corrected|floatformat:6 }}
Practical Implications

For QuantLib Users: When using BlackProcess for futures options, always use numerical Greeks or apply the manual correction (rho + dividendRho) to get accurate interest rate sensitivity.
